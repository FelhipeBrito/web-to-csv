Política de Privacidade — Web to CSV

Última atualização: 5 de setembro de 2026.

A extensão Web to CSV permite que o usuário visualize, copie e exporte tabelas HTML existentes na página que está aberta no navegador.

Dados tratados e finalidade

A extensão acessa o título da página e o conteúdo existente nas tabelas HTML da aba escolhida pelo usuário. Esses dados são usados exclusivamente para detectar as tabelas, apresentar a prévia solicitada e permitir sua cópia ou exportação.

Processamento local

Os dados são processados localmente no dispositivo, somente após o usuário abrir a extensão na aba ativa. O conteúdo tratado não é enviado para servidores externos e não pode ser acessado pelo desenvolvedor.

Coleta e armazenamento

A extensão não registra os dados para uso posterior e não transmite, vende ou compartilha conteúdo de páginas, histórico de navegação ou dados de uso. Os dados permanecem temporariamente na memória do popup e são descartados quando ele é fechado, exceto pela cópia ou pelo arquivo que o próprio usuário decidir criar. Não há contas, analytics, publicidade, cookies próprios ou banco de dados.

Área de transferência e arquivos

Ao selecionar “Copiar”, os dados escolhidos são gravados na área de transferência do próprio dispositivo. Ao selecionar “Exportar”, um arquivo CSV é gerado localmente e salvo por meio do fluxo normal de download do navegador.

Permissões

  • activeTab: concede acesso temporário somente à aba em que o usuário abriu a extensão.
  • scripting: permite executar o código empacotado da extensão nessa aba para localizar e ler tabelas HTML.

A extensão não solicita acesso permanente a todos os sites.

Serviços de terceiros

A extensão não usa serviços de terceiros, não carrega código remoto e não compartilha dados com terceiros.

Uso limitado

O uso dos dados acessados é limitado à finalidade única e visível da extensão: transformar tabelas HTML escolhidas pelo usuário em dados para prévia, cópia e exportação. Os dados não são usados para publicidade, perfilamento, análise comportamental ou qualquer finalidade não relacionada, em conformidade com os requisitos de Uso Limitado da Política de Dados do Usuário da Chrome Web Store.

Alterações nesta política

Esta política poderá ser atualizada se o comportamento da extensão mudar. Qualquer versão futura deverá continuar descrevendo fielmente as funcionalidades publicadas.

Contato

Para dúvidas sobre privacidade, entre em contato pelo e-mail de suporte informado na página oficial da extensão na Chrome Web Store.
